Accessibility statement

I want this portfolio to be readable and usable by people with different access needs. This statement describes the current site, its checks, and its remaining limitations.

Features and checks

  • Descriptive links, semantic headings, English language metadata, a skip link, and visible keyboard focus.
  • Scalable text and a flexible layout for smaller screens.
  • A written summary and relationship key accompany the external Kumu map.
  • WebAIM Contrast Checker results: body text #172B40 on white has a 14.42:1 ratio; links #174F86 on white have an 8.4:1 ratio. Both pass WCAG AAA for normal text. Links also use underlines.

Known limitations

The external Kumu map may be difficult to use with assistive technology. The portfolio provides its main findings in text, but this is not a complete equivalent of every interactive feature. Screen reader testing and a comprehensive accessibility audit have not been completed.

The current homepage has no images. Earlier assignments from weeks 1–8 have not been uploaded, so their images and alternative text cannot yet be audited. Meaningful images will need descriptive alternative text; decorative images will use empty alternative text.
